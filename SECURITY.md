# Security

If you find a way to read or change a poll without its link, get around the rate limits or Turnstile, or anything else that puts people's answers at risk, please report it privately through [GitHub's vulnerability reporting](https://github.com/mxrtcendik/overlap/security/advisories/new), not in a public issue.

Include what you did and what happened. I'll reply within a week and let you know when it's fixed.

Only the latest version on `main` is supported.
